## Marlin 2.1

The Anycubic Mega Zero 2.0 is a very old machine, but it is still supported by Marlin and it's great supporters. Projects like KADs [Anycubic Mega Zero Marlin Repository](//https://github.com/kad/Marlin?tab=readme-ov-file) show that old hardware can still benefit from new software. This fork hosts the branch 2.1.2.5 because it allows the printer to use new features like Linear Advance, Frequency Limit and Host Action Commands, whereas I couldn't activate all those features with newer versions. It's an old machine, and you're probably better off running Klipper.
